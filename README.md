# Reinvented Works

A static marketing website for the Reinvented Works dual smart switch cover plate. The site highlights the product’s flush-fit design, screwless installation, material benefits, compatibility, and purchase CTA in a polished storefront layout.

## Project Overview

This project is a lightweight front-end landing page built with:

- HTML
- CSS
- JavaScript
- No build step or framework required

The page includes:

- hero section and product messaging
- feature highlights
- comparison against competing switch plates
- product gallery and FAQ
- light/dark theme toggle
- responsive mobile navigation

## Project Structure

- `index.html` — main page structure and content
- `style.css` — layout, theme, responsive styling, and UI components
- `script.js` — theme switch, navigation behavior, and simple interactions
- `images/` — product and brand assets

## Notes

- The design uses custom fonts loaded from Fontshare.
- The site is fully static and can be hosted on GitHub Pages, Netlify, Vercel, or any basic static hosting provider.
- Assets are stored in the `images/` folder and referenced directly from the HTML.
